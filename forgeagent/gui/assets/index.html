模型配置
每个配置 = 一组注入 agentd 的环境变量（AGENTD_*），存于 ~/.agentd/gui/models.json。 后端可选：ollama / openai_compat / mimo / zhipu。切换即热切换（不重启 agentd， 下一轮对话生效），当前会话历史保留。一个 provider 下可在「模型名」里用逗号填多个模型，会话内随时切换。
下面的 token 上限是每个配置单独一份的：本机 qwen3.5 常见窗口 4k~40k， 云端 GLM / MiMo 是 128k —— 差三倍以上，做成全局一个值必然"一边严重浪费、 一边静默溢出"。留空 = 不改（保持该配置原来的值），填 0 = 不限。
Agent 请求执行一个操作

新建空间
空间 = 一个具名工作目录。在这个空间下开会话，会话就自动绑定到该目录，agent 的文件操作以它为根。 不填目录则落在 ~/.agentd/spaces/<空间名>。
